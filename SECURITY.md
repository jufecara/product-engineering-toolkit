# Security policy

## Scope

This repository contains natural-language workflows, templates, and plugin metadata. It does not provide a security certification, penetration test, compliance determination, or guarantee that a reviewed project is safe.

## Safe use

- Review generated findings before acting on them.
- Do not provide secrets, credentials, or unnecessary personal data as review input.
- Do not use the security skill to exploit systems or access production data without authorization.
- Treat all findings as hypotheses until verified by the appropriate owner.

## Reporting a problem

For a security issue in this repository, open a private report through the repository’s GitHub security contact if enabled. Otherwise, open a GitHub issue without including secrets or exploitable details, and request a private channel from the maintainers.
